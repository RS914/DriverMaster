# DriverMaster
A lightweight, multi-language PowerShell utility designed for system administrators and power users to scan hardware, manage local driver backups, create automated rescue USBs, and cleanly install hardware drivers—preventing common display conflicts (such as integrated vs. dedicated GPU clashes).
Open PowerShell in admin type this: "irm https://raw.githubusercontent.com/RS914/DriverMaster/main/DM.ps1 |iex"
